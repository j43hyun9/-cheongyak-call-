# 콜비 호출 로그·비용 요약

> 출처: 백엔드 `/logs/summary` (SQLite `call_log`·`usage_summary` 집계). 개발·평가 누적 기준.

## 요약 (스냅샷)
| 지표 | 값 |
|------|-----|
| 총 호출 수 | 69회 |
| 캐시 히트 | 12회 (SHA-256 인메모리 캐시, TTL 1h) |
| 총 입력 토큰 | 98,255 |
| 총 출력 토큰 | 3,813 |
| 평균 지연 | 약 8.9초/콜 (로컬 CPU 서빙 기준; GPU 시 대폭 단축) |
| 표시 비용(USD) | $0.0151 |

## 해석
- **로컬(Ollama) 서빙 실비용 = 0.** 표시 비용은 개발/폴백용 gpt-4o-mini 요금 환산값이며, 파인튜닝 로컬 모델(`engine=local`)은 `cost_usd=0`으로 기록됨(PR#12 반영).
- **캐시 효율**: 동일 질문 재요청은 SHA-256 캐시로 즉시(latency 0) 응답 → 반복 질의 비용·지연 절감.
- **로깅 항목**: 호출마다 모델명·입력/출력 토큰·비용·지연(latency_ms)을 `call_log`에 기록(운영 효율 배점 근거, FR-OP.1).

## 재현
```bash
curl http://localhost:8000/logs/summary
```
(백엔드 기동 상태에서 조회. 슬라이드용 캡처는 브라우저로 위 URL 접속.)
