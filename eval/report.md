## 3. 정성 평가 — 파인튜닝 전/후 (요약)

동일 질문에 대한 base(프롬프트만) vs 파인튜닝 콜비 비교 (상세 `eval/finetune_before_after.md`).

| 축 | BEFORE (base Qwen) | AFTER (파인튜닝 콜비) |
|---|---|---|
| 어투 | 존댓말·번호 리스트 | 반말·탐정 톤("수사 개시 🕵️ … 사건 해결 🔍") |
| 페르소나 | 이탈 유도에 순응("물론이죠") | 방어("나는 콜비야! 😎") |
| 가드레일 | 조언 뉘앙스 | 명확 거절("🚫 … 본인 몫 💪") |
| 할루시네이션 | 장황한 추정 나열 | "🗂️ 내 파일에 없어" 솔직 |
| 일정(RAG 제거) | 장황 + 중국어 혼입 | "캘린더에서 확인해봐 📅" |

→ base의 언어 혼입·페르소나 이탈이 파인튜닝으로 해소됨.

## 5. 방법론

1. **데이터 확보**: 콜비 어투 "질문→답변" 200건 (few-shot·페르소나 카드 시드 → LLM 증강 → 검수, held-out 30 분리)
2. **파인튜닝**: 사전학습모델 Qwen2.5-7B-Instruct에 QLoRA(4bit) — Unsloth, train 180/val 20, 3 epoch, assistant 응답만 학습(train_on_responses_only)
3. **서빙**: 어댑터 병합 → GGUF q8_0 → Ollama `colbi-qwen`(temperature 0.4) → 백엔드 `/chat` local 엔진
4. **평가**: held-out 30문항 × 루브릭 5축, GPT-4o LLM-as-Judge

## 7. 한계·개선 제안

- **사실 정밀도**: 일부 세부 수치(증거금 예시·의무보유확약 기간·배정 입고시점)에서 미세한 부정확 → 해당 주제 정확 예시를 학습 데이터에 보강하면 사실성 축 추가 향상 가능.
- **서빙 성능**: 로컬 CPU 기준 지연 약 6초 → GPU 서빙 또는 경량 모델(Qwen2.5-3B)로 응답 속도 개선 가능.
- **평가 확장**: 멀티턴 문맥 유지·엣지케이스 문항 추가.
