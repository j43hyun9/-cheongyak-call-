## 4. 비용·성능
- 총 30콜 비용: **$0.01365** (gpt-4o-mini) → 1콜 평균 약 $0.00046
- 응답 지연: 평균 약 3~4초/콜

## 5. 개선 제안
- **자동 채점 정교화**: 휴리스틱이 #24·#29를 REVIEW로 오분류 → LLM-as-Judge(별도 모델로 checkpoint 충족 판정) 도입 시 주관 카테고리까지 자동화 가능
- **이모지 과다**: 일부 응답에 이모지가 많음 → 필요 시 프롬프트에서 "이모지 1~2개" 제한 (장두호 프롬프트 튜닝)
- **평가셋 확장**: 엣지케이스(모호한 질문, 멀티턴 문맥 유지) 추가
