### 2-1. 캐시 히트 시 `sources` 소실 (구조적 버그)

`backend/main.py`의 `/chat`이 캐시 히트하면 `retrieve()`를 안 타고 `sources=[]`를 강제 반환한다. `cache.set()`이 답변 텍스트만 저장하고 `sources`는 저장하지 않기 때문 — **RAG 재도입의 핵심 가치(근거 기반 답변)와 충돌하는 구조적 버그**. 시각화: `docs/시스템_구성도.md`(PR#20) 그림1의 점선 단축경로.

### 2-2. RAG 검색 실패 — 표현 차이

"균등배분/비례배분" 질문에 `backend/rag/concepts.jsonl`에 정확한 문서(`gyunjeong_baejeong`, `birye_baejeong`)가 있는데도 못 찾고 무관한 문서("따상")만 인용됨. 질문의 "배**분**" vs 코퍼스의 "배**정**" 표현 차이가 원인으로 추정 — 장두호가 8/20에 고친 슬랭 랭킹 이슈(코퍼스 크기 불균형)와는 별개의 새 이슈.

### 2-3. 슬랭 인식 — STT 레벨 공통 한계

"따상이 뭐야"는 Whisper API·faster-whisper·SenseVoice **3개 엔진 전부 실패**(각각 "빠상"/"따 3"/"빠 상"). 모델 크기보다 학습 데이터 자체에 이 단어가 거의 없어서로 추정 — STT를 더 좋은 엔진으로 바꿔도 해결 안 될 가능성이 높고, RAG concept 문서에 발음 변형까지 커버하는 쪽이 더 현실적인 해법.

### 2-4. 로컬 CPU 추론 지연

캐시 미스 시 약 18초. 실서비스라면 GPU 서빙이나 경량 모델(Qwen2.5-3B)로 개선 여지가 있으나, 부트캠프 범위에서는 **발표 데모 때 로딩 연출(아바타 thinking 상태 유지 등)로 체감을 관리하는 게 현실적**.

### 2-5. 프론트 실연동 — 완료, 신규 이슈 2건 발견 (2026-08-24 갱신)

PR#23(`feature/ai-human-persona-mobile-polish`)로 AI Human 탭이 `/stt`→`/chat`(RAG)→`/tts` 파이프라인을 실제로 순차 호출하도록 연동됐다(PR#19는 아바타 UI·상태머신까지만이었음). 코드 리뷰 + 외부 데모 실측으로 검증한 결과 핵심 파이프라인은 정상 동작하지만, 아래 두 가지 이슈가 새로 발견됐다.

### 2-6. RAG sources ↔ SourceCard 필드 불일치

`/chat`이 반환하는 RAG `sources`는 `{title, snippet, type, url}` 형태(`backend/rag/colbi_rag.py`의 `retrieve()` 계약)인데, AI Human 화면의 `SourceCard`는 `/ipo/schedule` 형태(`{name, start, end, price, underwriter}`)를 기대한다(`frontend/src/pages/ColbyAvatarPage.jsx:126`). sources가 붙는 응답마다 빈 카드(`📋 `, `📅  ~ `)로 렌더링된다. 기존엔 하드코딩된 목업 데이터(올바른 형태)만 넣어봐서 드러나지 않았던 문제 — PR#23이 처음으로 실제 RAG sources를 이 경로에 연결했다.

### 2-7. 데모 환경 타임아웃 시 Mock 응답으로 조용히 폴백

외부 cloudflared 데모에서 새 세션·새 질문으로 `/chat`을 호출했을 때, 캐시 미스로 추론이 오래 걸리는 경우(18~40초+, 항목 4) 응답이 클라이언트에 안 돌아오는 걸 확인했다. 백엔드는 처리를 끝내고 캐시엔 실제로 저장하지만(재요청하면 즉시 캐시 히트), 원 요청의 HTTP 응답만 못 돌아온다 — 무료 cloudflared 퀵터널의 idle/proxy 타임아웃으로 추정된다. `frontend/src/api.js`의 `postChat()`이 이런 네트워크 에러를 조용히 Mock 응답("지금은 백엔드 연결 전 Mock 모드예요")으로 대체하도록 설계돼 있어서, 실제로는 백엔드가 정상 작동 중인데도 화면엔 "연결 안 된 것"처럼 보인다. 코드 버그라기보단 무료 터널 인프라 한계 + 기존 추론 지연(항목 4)의 조합이지만, 발표 데모 때도 재현될 수 있어 별도 항목으로 기록한다.

### 2-8. (해결됨) colbi-qwen 이모지·고정 멘트 강제 출력

`colbi-qwen`(로컬 파인튜닝 모델)에 시스템 프롬프트로 이모지 금지 지시를 넣어도 파인튜닝 과정에서 학습된 🔍/🕵️·"수사 개시!"/"사건 해결!"/"단서 발견!" 같은 고정 패턴이 계속 출력되던 문제(2026-08-21 발견). 프롬프트만으로는 억제 불가함을 실측으로 확인 후, PR#23에서 `backend/persona/sanitize.py`(`strip_persona_artifacts()`)로 서버사이드 후처리를 추가해 해결됨 — 신규 응답·캐시 응답 양쪽에 동일하게 적용된다.

**가드레일 문구 오탐 — 해결 (2026-08-24)**: 최초 반영(`a0dc5cde`, 2026-08-21) 시점엔 문두 고정 멘트 제거 목록(`_FIXED_PHRASES`)에 정상적인 투자거절 가드레일 문구("그 단서는 못 줘.", "내 파일에 없어...")가 함께 들어 있어, 콜비가 실제로 투자 권유를 거절하는 답변을 장식 멘트로 오인해 통째로 삭제해버릴 수 있었다(PR#23 리뷰 코멘트로 지적, 최악의 경우 가드레일 문구가 빈 문자열이 되어 그대로 캐시·응답됨). 후속 커밋(`84faa43e`)에서 두 가드레일 문구를 제거 목록에서 빼고, 정제 결과가 통째로 비어버리면 이모지만 제거한 원문으로 되돌리는 안전장치를 추가해 해결됨(임강 재확인 완료, PR#23 merge에 포함).
